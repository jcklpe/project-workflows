# Agent Instructions
This repository owns reusable project workflow skills and their templates. An adopting project's actual documents stay in its parent repository. When working on an adopted copy, read the parent instructions and workflow.toml; never infer the current project from a global installation path.

## Changes and verification
Preserve intentional project divergence, complete supporting files, license notices, and source attribution. Keep prose paragraphs on single lines and avoid unrelated reformatting. Read skills/commit-work/SKILL.md before checkpoints. Use scoped pathspec commits, guard new-file additions with ignore checks, never add co-author trailers, and never push. Preserve concurrent work and do not rewrite history without explicit authorization.

Validate changed frontmatter, relative resources, TOML configuration, ignores, and relevant workflow behavior. No runtime or service credentials are required. Do not add tests solely to mirror prose. Real .workflow.env values remain ignored; public branches must not contain private project details, credentials, or personal paths. Templates are inputs to adapt, not instructions to overwrite an existing project.
